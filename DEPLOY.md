# Как выложить LunoCase в Telegram-бота

Как пользоваться админкой после запуска: см. ADMIN_GUIDE.md.

Приложение это обычный сайт (Node.js) плюс бот. Нужны: бот, сервер с https-адресом и несколько настроек. Время: около часа.

## 1. Создай бота
1. Открой в Telegram @BotFather, команда `/newbot`, придумай название и username (например `LunoCaseBot`).
2. Скопируй токен (строка вида `123456:ABC...`). Это секрет, никому не показывай.
3. Оплата Stars отдельно подключать не нужно: она работает у любого бота.

## 2. Купи сервер и домен
Mini App открывается только по https, поэтому нужен домен.
- Домен: любой регистратор, около 10 долларов в год.
- Сервер (VPS): Ubuntu 22.04 или 24.04, 1 ГБ памяти хватит на старте (Hetzner, Timeweb, Selectel и подобные). Направь домен на IP сервера (запись типа A).
- Вариант без VPS: Render, Railway или Fly.io. Нужно подключить постоянный диск (volume), иначе данные пропадут при перезапуске (см. раздел 6).

## 3. Установи и запусти на VPS
Заходишь на сервер по SSH:
```
# Node.js 20 или новее
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs unzip
# распакуй архив luno-server.zip в /opt/luno и зайди туда
cd /opt/luno-server
cp .env.example .env     # открой .env и впиши свои значения (раздел 4)
sudo npm install -g pm2
pm2 start "node --env-file=.env server.js" --name luno
pm2 save && pm2 startup   # автозапуск после перезагрузки
```
(`--env-file` работает в Node 20.6+. Если Node старше, задай переменные через `export` перед запуском.)

## 4. Переменные (файл .env)
| Переменная | Что это |
|---|---|
| BOT_TOKEN | токен бота из BotFather |
| ADMIN_TOKEN | длинный пароль для админки (придумай 20+ символов) |
| PUBLIC_URL | адрес сайта, например `https://luno.example.com` (нужен для оплаты Stars) |
| ADMIN_CHAT_ID | твой числовой ID в Telegram (узнать у @userinfobot), туда приходят заявки на вывод |
| TON_ADDRESS | адрес твоего кошелька TON для пополнений (необязательно) |
| TON_API_KEY | ключ toncenter.com (необязательно, но желательно) |
| DATA | путь к файлу данных, например `/data/data.json` |
| UPLOADS | папка для загруженных картинок, например `/data/uploads` |
| PORT | порт, по умолчанию 3000 |

## 5. HTTPS через Caddy (самый простой способ)
```
sudo apt install -y caddy
```
Файл `/etc/caddy/Caddyfile`:
```
luno.example.com {
    reverse_proxy localhost:3000
}
```
`sudo systemctl reload caddy`. Сертификат получится сам. Открой `https://luno.example.com`: должна появиться страница приложения (в браузере она покажет «Открой приложение из Telegram», это нормально).

## 6. Постоянный диск (важно)
Все данные игроков лежат в `DATA`, картинки в `UPLOADS`. Эти пути должны быть на диске, который не стирается. На VPS это любая папка вроде `/data`. На Render, Railway и Fly подключи volume и укажи его путь. Без этого при перезапуске всё обнулится.

## 7. Подключи приложение к боту
1. @BotFather → твой бот → Bot Settings → Configure Mini App → Enable → вставь `https://luno.example.com`.
2. Там же Menu Button → Configure → тот же адрес, название кнопки «Играть».
3. Ссылка для игроков: `https://t.me/ИмяБота?startapp=` (рефералы работают через неё).
Открой бота, нажми «Играть» и проверь, что приложение открывается и показывает твоё имя.

## 8. Настрой через админку
Открой `https://luno.example.com/admin`, введи ADMIN_TOKEN:
- Настройки: имя бота (для реферальных ссылок), контакт поддержки, процент прибыли по играм, лимиты, комиссия за вывод.
- «Стартовый баланс новичка» поставь **0** (иначе все новички получают бесплатные звёзды).
- NFT и подарки, Кейсы, Режимы и картинки, Промокоды: наполни под себя.

## 9. Проверь деньги маленькой суммой
1. Пополни ★10 через Stars, убедись, что баланс вырос (в логе сервера должно быть «Webhook бота: ok»).
2. Если подключила TON, переведи минимальную сумму с комментарием из приложения и дождись зачисления.
3. Сделай тестовую заявку на вывод и обработай её в админке (вкладка «Выводы»).

## 10. Копии и безопасность
- Раз в день копируй файл `data.json` и папку `uploads` в другое место (cron или облако).
- ADMIN_TOKEN никому не передавай, адрес /admin лучше не публиковать.
- Следи за обновлениями сервера (`sudo apt update && sudo apt upgrade`).
- Игра на реальные деньги требует соблюдения закона твоей страны и правил платёжных систем и Telegram. Это твоя ответственность как владельца.

## Быстрый тест без сервера
На своём компьютере: `DEV=1 ADMIN_TOKEN=test node server.js`, затем открой http://localhost:3000/?dev=1. Чтобы открыть в настоящем Telegram с компьютера без хостинга, можно временно пробросить порт через cloudflared или ngrok и вписать полученный https-адрес в BotFather.
