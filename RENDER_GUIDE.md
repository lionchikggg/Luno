# Запуск на Render: пошагово (около 30 минут)

Тебе понадобятся: аккаунт на GitHub (бесплатно), аккаунт на Render, Telegram, банковская карта для оплаты хостинга (около 7 долларов в месяц).

## Шаг 1. Токен бота
1. В Telegram найди @BotFather, отправь `/newbot`.
2. Придумай название (например LunoCase) и username, который заканчивается на `bot` (например `LunoCaseBot`).
3. BotFather пришлёт токен: длинная строка с двоеточием. Сохрани её в заметки. Никому не показывай.

## Шаг 2. Твой Telegram ID
Найди бота @userinfobot, нажми Start. Он пришлёт число (Id). Сохрани: оно нужно, чтобы бот присылал тебе заявки на вывод.

## Шаг 3. Пароль админки
Придумай длинный пароль (20+ символов, буквы и цифры). Сохрани в заметки. Это будет ADMIN_TOKEN.

## Шаг 4. Положи файлы на GitHub
1. Зайди на github.com, зарегистрируйся, нажми «+» справа вверху, «New repository». Название любое (например luno), выбери **Private**, нажми «Create repository».
2. На странице нового репозитория нажми ссылку «uploading an existing file».
3. Распакуй архив luno-server.zip на компьютере. Выдели **всё содержимое папки luno-server** (файлы и папку public) и перетащи в окно браузера. Подожди загрузки и нажми «Commit changes».
   Важно: файл render.yaml, Dockerfile и server.js должны лежать в корне репозитория, а не внутри папки.

## Шаг 5. Создай сервис на Render
1. Зайди на render.com, зарегистрируйся через GitHub («Sign in with GitHub»), разреши доступ к репозиторию luno.
2. Нажми «New +» → «Blueprint», выбери репозиторий luno.
3. Render покажет, что создаст сервис с диском. Название сервиса должно быть уникальным: если Render говорит, что занято, поменяй `name` в файле render.yaml на GitHub (например luno-case-2024) и повтори.
4. Заполни поля переменных:
   - BOT_TOKEN: токен из шага 1
   - ADMIN_TOKEN: пароль из шага 3
   - ADMIN_CHAT_ID: число из шага 2
   - PUBLIC_URL: пока впиши `https://luno-case.onrender.com` (замени luno-case на название сервиса)
   - TON_ADDRESS и TON_API_KEY: если TON пока не нужен, оставь пустыми
5. Нажми «Apply» и жди 3–5 минут, пока сервис станет «Live» (зелёный).

## Шаг 6. Проверь адрес
Наверху страницы сервиса Render показывает адрес вида `https://luno-case.onrender.com`. Открой его в браузере: должна появиться страница «Открой приложение из Telegram». Если адрес отличается от того, что ты вписала в PUBLIC_URL, зайди в Environment, поправь PUBLIC_URL на настоящий адрес и сохрани (сервис перезапустится сам).

## Шаг 7. Подключи к боту
1. В @BotFather: `/mybots` → твой бот → Bot Settings → Configure Mini App → Enable → вставь адрес сайта.
2. Там же: Menu Button → Configure → тот же адрес, название кнопки «Играть».
3. Открой бота, нажми «Играть»: приложение должно открыться.

## Шаг 8. Настрой админку
Открой `твой-адрес/admin`, введи пароль из шага 3 и пройди вкладку «Начало работы». Обязательно: «Стартовый баланс новичка» = 0, имя бота, контакт поддержки.

## Шаг 9. Проверь деньги маленькой суммой
Пополни ★10 через Stars и убедись, что баланс вырос. Сделай тестовую заявку на вывод и обработай её в админке.

## Если что-то не так
- «Application failed» или красная точка: открой вкладку Logs на странице сервиса, скопируй последние строки и пришли мне.
- Приложение открывается, но Stars не зачисляются: проверь, что PUBLIC_URL точно совпадает с адресом сайта, в Logs должна быть строка «Webhook бота: ok».
- Данные пропали после обновления: проверь, что диск подключён в разделе Disks (путь /data).
